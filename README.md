# siftframe

Sift color frame values and contrast-safe presentation helpers.

**Site:** https://theworker02.github.io/siftframe/

## Install / run

```bash
git clone https://github.com/theworker02/siftframe.git
cd siftframe
node src/cli.js
node --test
```
